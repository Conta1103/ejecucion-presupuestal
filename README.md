# Ejecución Presupuestal SIIF — DESAJ Sincelejo

Herramienta de análisis de ejecución presupuestal basada en la **Guía Financiera No. 12** del SIIF Nación, diseñada para la **Dirección Seccional de Administración Judicial de Sincelejo** — Rama Judicial de Colombia.

## Características

- **Carga múltiple**: hasta 3 unidades ejecutoras simultáneamente
- **Cadena presupuestal completa**: Apropiación → CDP → Compromiso → Obligación → Orden de pago → Pago
- **Índice de Salud Presupuestal**: indicador compuesto con gauge visual
- **Sistema semáforo**: verde (≥80%), amarillo (50–79%), rojo (<50%)
- **4 gráficas con análisis**: embudo, donut, barras y radar, cada una con interpretación automática
- **Comparativo entre UE**: análisis lado a lado de unidades ejecutoras
- **Alertas de auditoría**: detección automática de rezagos, sobre-ejecución y brechas
- **Generación de PDF**: informe completo con KPIs, tabla, análisis de gráficas e índice de salud
- **Tema claro/oscuro**: adaptación automática al tema del navegador

## Uso

1. Abre `index.html` en el navegador (o accede via GitHub Pages)
2. Carga uno o más archivos `.xlsx` del reporte de ejecución presupuestal del SIIF Nación
3. Navega entre las pestañas: Cadena presupuestal, Gráficas, Comparativo UE, Alertas de auditoría
4. Genera el PDF con el botón en el encabezado

## Formato de archivo

Reporte de ejecución presupuestal exportado del SIIF Nación (`.xlsx`), con estructura estándar de columnas incluyendo TIPO, CTA, SUBC, OBJG, ORD, SORD, ITEM, SITEM, CONCEPTO, FUENTE, SITUACIÓN, y toda la cadena presupuestal del gasto.
